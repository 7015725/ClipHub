# ClipHub

ClipHub 是面向 Android / ShortX 的全局剪贴板浮窗，运行模块保持 Rhino ES5 兼容。

## 用户版更新记录

### `20260809.05`

本次更新重点优化大数据列表性能、分页体验、浮窗稳定性和界面一致性。

- 新增 AJAX 追加和数字分页，可自定义每页加载 5～1000 条。
- 新增懒加载、下一页预加载、虚拟数据窗口和分帧渲染，大数据列表滚动更顺畅。
- 首页长文本仅加载约 200 字符预览，复制、编辑、翻译和详情仍使用完整内容。
- 优化数据新增、删除、置顶和筛选后的滚动位置恢复。
- 统一首页、设置页及其他浮窗的顶部拖动区域和视觉样式。
- 修复高级筛选刷新时的闪帧、短暂空白和滚动锚点漂移。
- 修复快速打开、关闭或切换详情、编辑、筛选、设置、翻译窗口时的潜在崩溃和窗口残留。
- 加强 Rhino / ColorOS 颜色接口安全，设置模块改为离线自包含。

本次更新不修改数据库结构，不清空或迁移现有剪贴板数据，也不改变剪贴板监听、去重、标签、敏感内容判断和分类规则。

- [详细技术更新说明](docs/ClipHub_20260809.05正式版详细更新说明.md)

## 正式入口

- 后台入口：`ClipHub.js`
- 全局剪贴板开关：`tasks/ClipHub_全局剪贴板开关.js`
- 模块清单：`module-manifest.json`

发布时必须同步入口与完整模块集合，不建议单独替换运行模块。
