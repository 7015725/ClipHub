# ClipHub main 合并前真机回归清单

测试分支：`main`

候选模块集：`20260819.08`

## 1. 启动与重复进入

- 启动 ClipHub 后台任务，再通过开关任务显示首页。
- 首页长按任意列表 chip，应进入对应文本的分词页。
- 返回首页后，再次长按同一 chip 和另一 chip，均应重新进入分词页。
- 快速执行“显示 → 隐藏 → 显示”，页面不得延迟重现、残留旧页面或出现无法点击的透明窗口。

## 2. 词块长文本

- 使用包含 2048 字符连续 URL、长邮箱和普通长文本的测试语料。
- 长词块应根据内容增高并完整换行，不得固定高度裁切。
- 点击、拖动选择、复制和输入均应获得完整原文，不得只处理可见部分。
- 纯空格、换行、制表符词块显示占位符，但复制后仍保持原始字符。

## 3. 正则精确分词

- 已勾选规则和临时正则同时参与；临时正则覆盖发生重叠的保存规则。
- 命中区间输出完整匹配，未命中区间连续保留，不调用普通分词器。
- 无任何命中时，整段原文成为一个未命中词块。
- 多个不连续词块复制或输入时，只拼接所选词块原文，不插入额外字符。
- 将所有词块按顺序拼接，结果必须与原文逐字符一致。
- 无效正则和零宽匹配显示规则级警告；命中超限或还原失败应清空结果并显示阻断错误。

## 4. 编辑页返回链

按顺序执行：

1. 首页长按 chip 进入分词页。
2. 选择词块并进入词块文本编辑页。
3. 键盘显示时首次 Back/侧滑，只隐藏键盘。
4. 再次侧滑，应返回分词页，不得直接返回首页。
5. 从分词页返回首页后，再次长按 chip，仍能进入分词页。

## 5. Google 翻译

- Google 翻译已安装且 Intent 启动成功：应打开 Google 翻译并关闭 ClipHub UI。
- Google 翻译未安装、文本为空或 Intent 启动失败：ClipHub UI 保持显示，并给出非崩溃提示。
- 百度、有道内置翻译流程不得因 Google 模式处理而自动关闭。

## 6. 生命周期与退出

- 关闭 ClipHub 后台任务后，不得残留窗口、延迟清理回调或页面 hook。
- 重新启动后台任务后，显示/隐藏、系统 Back、Predictive Back 和侧滑返回均只能触发一次。
- 最近任务退出、系统 Back 和开关任务隐藏后，不得发生延迟 attach 或首页自动重现。
