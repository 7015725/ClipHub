## 当前维护优先级

### P0：稳定性

- 所有页面继续遵守 Navigation Contract v2；
- 新页面不得增加导航核心 pageId 硬编码；
- 真机持续验证 IME、侧滑、Predictive Back 和快速显隐；
- 保持正则精确分词逐字符还原不变量；
- 保持 Google 外部 Intent 后 UI 生命周期可恢复。

### P1：性能

- 继续关注长列表、长正文、长词块与规则数量上升后的 UI 测量成本；
- 保持首页预览与按需完整正文读取；
- 避免每次剪贴板变化重建完整页面；
- 对新增功能先建立静态/回归门禁，再扩大运行路径。

### P2：文档与发布纪律

- `README.md` 只描述当前正式行为；
- `docs/` 只保留当前规范、当前版本说明和可复用模板；
- 阶段实施记录、probe 结果、旧版本说明统一进入 `archive/`；
- 修改运行模块必须同步 manifest SHA 与模块集版本；
- 自动化通过后仍需 Android 14 / ColorOS / ShortX 真机测试。

## 后续功能原则

新增功能默认遵循：

1. 不破坏现有数据库和 ShortX 运行目录；
2. Rhino ES5 only；
3. 新页面声明式注册，不修改导航核心；
4. UI 行为以首页视觉和交互基线为准；
5. 新增网络外发能力必须由用户主动触发；
6. 新增规则系统必须明确与现有高级筛选/分词规则的边界；
7. 为高风险路径增加可重复执行的回归测试。
