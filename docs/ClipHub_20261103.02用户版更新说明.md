# ClipHub `20261103.02` 更新日志

- 首页列表滑动更流畅，长列表快速上下滑动时卡顿与空白明显减少；修复快速下滑并触底加载时可能导致系统软重启的问题。
- 点击记录会先复制到剪贴板再输入，当前没有输入框时也能直接粘贴；首页和详情的时间显示带上日期。
- 设置新增主题、点击行为、来源记录、忽略应用、历史上限与保留天数；删除的记录进入回收站，30 天后自动彻底清除，也可在设置中立即彻底清除全部记录。
- 百度、有道未配置密钥时自动改用 Google 翻译；筛选无结果时可一键清除筛选。

更新渠道仍为 `main`。使用过测试分支的用户，请换回正式版后台入口后重新运行，完成模块同步。
