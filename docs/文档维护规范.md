# ClipHub 文档维护规范

## 当前文档区 `docs/`

只保留：

- 当前产品/交互/技术/模块契约；
- 当前 Navigation Contract；
- 当前正式版本更新说明；
- 当前真机回归清单；
- 可复用模板和必要图片。

## 历史区 `archive/`

以下内容完成阶段目标后必须迁入 `archive/`：

- Stage 实施记录；
- probe 说明与结果；
- Beta 发布记录；
- 已完成的二次分析/实施方案；
- 旧版本更新说明；
- 一次性 patch、payload、诊断输出；
- 被新契约替代的旧规范。

## 事实源优先级

1. `module-manifest.json`：模块集合、SHA、Export、runtimeRole、生命周期；
2. 当前正式代码：运行行为；
3. `README.md`：项目入口与正式功能摘要；
4. `docs/` 当前规范；
5. `archive/`：仅用于历史追溯，不得作为新开发默认依据。

发现文档与 manifest/当前代码冲突时，应优先修正文档，不得为迁就旧文档回退当前正式实现。
