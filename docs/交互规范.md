# ClipHub 交互规范

## 1. 总则

当前 ClipHub 采用单 Primary Window 页面宿主。首页、编辑、设置、标签、翻译、正则规则和分词等主要业务页面必须纳入统一页面栈，不再各自维护独立返回链。

## 2. 首页

首页包含：

- 顶部拖动/窗口操作区；
- 搜索与筛选入口；
- 来源、类型、标签等快捷筛选；
- 剪贴板列表；
- 新增入口与必要的底部操作区。

列表项支持：

- 点击执行当前定义的主操作；
- 置顶、编辑、删除、翻译；
- 标签操作；
- 拖动排序；
- 长按进入分词。

长文本列表只展示预览时，任何最终操作必须使用完整正文而不是预览文本。

## 3. 搜索与筛选

- 搜索输入使用防抖；
- 保留当前筛选状态并允许快速清除；
- 来源/类型/标签/置顶/敏感/正则规则的选中态必须清晰；
- 空结果、无数据与加载失败应有不同状态；
- 高级正则规则提供独立列表、编辑和测试入口。

## 4. 编辑

- 新增与编辑共享核心编辑能力；
- 内容为空不得保存；
- 保存操作防重复提交；
- 编辑器关闭后必须正确恢复 Primary Window 焦点；
- 软键盘出现时操作区不得被完全遮挡；
- 启用 IME First Back 的页面，第一次 Back 只隐藏键盘。

从分词词块进入编辑时，返回必须回到分词页，而不是跨层直接返回首页。

## 5. 分词页

进入分词页后按当前模式直接生成结果。

### 普通模式

用于快速选择中文、英文单词、数字和符号等普通词块。

### 正则模式

- 命中块与未命中块都显示；
- 未命中空白使用可见占位符，但复制/输入使用真实原字符；
- 长 URL、长邮箱和连续长文本词块必须自适应高度并完整换行；
- 词块可点击、拖动和长按选择；
- 多个不连续词块只按原文位置连接选中文本，不自动插入字符；
- 复制、输入和编辑使用完整词块原文。

## 6. 翻译

- 百度、有道模式在 ClipHub 内显示翻译结果；
- Google 模式向外部 Google 翻译发送完整文本；
- Google 成功打开后 ClipHub UI 自动隐藏；
- 外部 Intent 失败不得造成当前页面关闭或不可恢复。

## 7. Back 统一规则

以下入口必须进入同一 Back 状态机：

- Toolbar Back；
- 页面返回按钮；
- Android 系统 Back；
- 三键返回；
- Legacy `KEYCODE_BACK`；
- 侧滑返回；
- Predictive Back commit。

规则：

1. 一次 Back 最多 pop 一层；
2. 当前页面有 IME 且 `imeBackFirst=true` 时，第一次 Back 只隐藏输入法；
3. 焦点交回 Primary Window 后重新武装 Back；
4. 第二次 Back 再 pop 页面；
5. 首页 Back 关闭 ClipHub UI，但不停止后台剪贴板监听；
6. Predictive Back 的 start/progress/cancel 不修改页面栈，只有 commit 执行一次返回。

## 8. 页面重新进入

页面 mount/unmount 必须验证当前宿主代次和页面栈状态。

禁止：

- 关闭后旧 Handler 回调重新 attach 页面；
- 旧分词页面残留导致首页无法再次长按进入；
- 快速“显示 → 隐藏 → 显示”复用正在关闭的 View；
- 一个页面自己修改另一个页面的私有栈状态。

## 9. WindowManager

- 标题栏空白区域可拖动窗口；
- 按钮区域不得触发窗口拖动；
- 拖动结束后持久化位置；
- 窗口必须限制在安全显示区域；
- 屏幕旋转/尺寸变化后重新夹紧；
- 所有 remove 操作幂等；
- 关闭后不得残留 dim、透明遮罩或不可触摸区域。

## 10. 颜色与主题

- 所有 UI 颜色通过 Theme 安全桥应用；
- 不直接将 Rhino 数字传给存在 Java 重载歧义的颜色 API；
- 亮暗模式均需保证文字可读；
- 系统主题变化只执行必要刷新；
- 不使用持续空转动画。

## 11. 真机必测

至少覆盖：

1. 首页 → 分词 → 词块编辑 → Back 按层返回；
2. 返回首页后再次长按同一/其他词条能重新进入分词；
3. 长 URL、长邮箱、长普通文本完整显示；
4. 编辑页第一次 Back 隐藏 IME、第二次 Back 返回；
5. 系统侧滑、三键 Back、Toolbar Back 语义一致；
6. Predictive Back cancel 不改变页面栈、commit 只 pop 一层；
7. Google 翻译成功后 UI 隐藏，失败时 UI 保持；
8. 快速显示/隐藏/显示无旧页面重新 attach；
9. 关闭后无透明遮罩与 WindowManager 残留；
10. 后台 UI 关闭后剪贴板监听仍正常入库。
