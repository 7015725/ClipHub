# ClipHub 产品需求

## 1. 文档状态

- 状态：当前产品契约
- 分支：`main`
- 当前正式模块集：`20260819.08`
- 平台：Android / ShortX / Rhino ES5

本文只描述当前仍有效的产品目标与边界。历史首版阶段划分、已完成施工计划与探针记录统一保存在 `archive/`。

## 2. 产品目标

ClipHub 是面向 Android / ShortX 的全局剪贴板悬浮工具，目标是让用户在不中断当前应用上下文的情况下完成：

- 剪贴板历史查看与再次输入；
- 搜索、来源/类型/标签/正则筛选；
- 新增、编辑、删除、置顶和拖动排序；
- 翻译；
- 普通分词与正则精确分词；
- 通过统一页面栈完成可预测的 Back 与手势交互。

## 3. 当前核心功能

### 3.1 剪贴板历史

- 全局监听并保存文本剪贴板；
- 本地 SQLite 持久化；
- 记录复制时间、来源信息、内容类型和标签；
- 自身写入回环抑制与短时间重复控制；
- 支持敏感内容策略和历史清理；
- 主数据库 Schema 维持兼容升级，不因 UI 功能更新清空历史。

### 3.2 列表与分页

- 首页显示剪贴板列表；
- 支持置顶、编辑、新增、删除、拖动排序；
- 支持 AJAX 追加、数字分页、懒加载、预加载和虚拟数据窗口；
- 长正文首页可只读预览，真正执行复制、输入、编辑、翻译、分词时读取完整正文。

### 3.3 搜索与筛选

支持：

- 关键词；
- 来源应用；
- 内容类型；
- 标签；
- 置顶；
- 敏感；
- 高级正则规则。

不同维度组合使用 AND，同维度多选按该维度定义组合语义。

### 3.4 翻译

- 百度、有道：ClipHub 内置结果页；
- Google：通过 Android Intent 发送完整文本；
- Google 成功启动后自动隐藏 ClipHub UI；
- 未安装、空文本或 Intent 失败时不得崩溃，并保留 ClipHub 供用户继续操作。

### 3.5 文本分词

入口：

- 首页长按剪贴板词条；
- 编辑页分词入口。

模式：

- 普通分词；
- 正则精确分词。

词块支持点击、拖动、长按选择，并可复制、输入或编辑。

正则精确分词要求：

- 只按当前启用规则与临时正则的最终匹配区间切割；
- 未命中区间连续保留；
- 不调用普通分词器二次切割；
- 临时正则最高优先级；
- 重叠按“优先级 → 更长匹配 → 规则稳定顺序”裁决；
- 成功结果全部词块拼接后必须 100% 还原原文；
- 无效/零宽匹配警告；超限或还原失败整次阻断。

分词规则与高级筛选正则规则是两套独立配置。

## 4. 页面与导航

所有主要页面必须进入统一 Primary Window 页面宿主。

当前导航契约：

- `PageRegistry`：页面定义；
- `PageStack`：页面历史；
- `Navigator`：导航动作；
- `BackDispatcher`：Back 决策；
- `UIShell`：页面挂载。

系统侧滑、三键 Back、Toolbar Back、Legacy Back 与 Predictive Back 必须保持一致语义。

IME 页面启用 `imeBackFirst` 时：第一次 Back 隐藏输入法，第二次 Back 返回上一页。

## 5. 窗口与显隐

- 主 UI 为 WindowManager 悬浮窗口；
- 窗口位置和尺寸必须限制在安全区域；
- 屏幕尺寸变化后重新夹紧；
- 所有关闭路径必须幂等；
- 关闭 UI 不等于停止后台实例；
- 进入后台或外部 Intent 后不得由过期回调重新显示旧页面；
- 关闭后不得残留透明遮罩、不可触摸层或失效 View 引用。

## 6. 隐私与安全

- 默认本地保存；
- 日志不得输出完整剪贴板正文、令牌或敏感配置；
- 网络翻译仅在用户主动调用时执行；
- 忽略应用、敏感策略、历史上限和保留时长由用户配置；
- 导出或外发行为必须由用户显式触发。

## 7. 正式入口

正式用户工作流只依赖：

```text
ClipHub.js
tasks/ClipHub_全局剪贴板开关.js
```

后台入口负责持续监听；开关任务负责显示/隐藏 UI。

## 8. 发布阻断条件

以下任一问题出现时不得视为正式可发布：

- Rhino ES5 校验失败；
- manifest SHA/export/lifecycle contract 不一致；
- ColorOS 颜色安全审计存在 HIGH/WARN；
- Navigation/Tokenizer/Translation 自动回归失败；
- 正则精确分词无法逐字符还原原文；
- 真机 Back/IME/侧滑/外部 Intent 出现跨层返回或 UI 残留；
- 正式入口与 `main` manifest 不一致。
