# ClipHub `20260809.05` 用户版更新说明

本次正式更新重点优化大数据列表性能、分页体验、浮窗稳定性和界面一致性。

## 新增与优化

- 新增 AJAX 追加和数字分页两种加载方式，可在设置页切换。
- 支持自定义每页加载 5～1000 条，默认 100 条。
- 新增懒加载和下一页预加载，减少大量数据一次性加载造成的卡顿。
- 首页长文本只加载约 200 字符预览，复制、编辑、翻译和详情仍可读取完整内容。
- 优化列表滚动和 View 复用，减少频繁重建、掉帧和滚动位置跳动。
- 优化数据新增、删除、置顶和筛选后的滚动位置恢复。
- 统一首页、设置页及其他浮窗的顶部拖动区域和视觉样式。
- 修复高级筛选抽屉刷新时的闪帧、短暂空白和滚动锚点漂移。
- 修复快速打开、关闭或切换详情、编辑、筛选、设置、翻译窗口时的潜在崩溃和窗口残留。
- 加强 Rhino/ColorOS 颜色接口安全，降低主题颜色调用导致异常的风险。
- 设置模块改为离线自包含，不再依赖运行时网络下载页面源码。

## 数据与兼容性

- 不修改数据库结构，不会清空或迁移现有剪贴板数据。
- 不改变剪贴板监听、去重、标签、敏感内容判断和分类规则。
- 保持现有拖动、缩放、IME 避让和控制开关逻辑。
- 入口版本升级为 6，启动时会自动同步完整的 `20260809.05` 模块集合。

`20260809.05` 沿用已完成真机验证的 `20260809.04` 功能模块，仅将正式更新源切换为 `main`，模块内容不变。

- 启动和模块同步正常。
- 首页、分页、详情、编辑、高级筛选、设置和翻译测试正常。
- 连续快速打开和关闭浮窗正常。
- 未发现崩溃、残影、闪帧或无法重新打开的问题。
